# 财报深析与红旗

## 九大块（deep.py）
1. 杜邦分解：ROE = 归母净利率 × 总资产周转率 × 权益乘数，并做三因子同比归因
2. 周转与现金周期：DSO / DIO / DPO / CCC（按报告期天数年化）
3. 现金流形态：经营/投资/筹资 八象限画像 + FCF 与 FCF 利润率
4. 盈利质量：净现比、扣非净利率、非经常性占比、应计比率分级
5. 税负：实际税率 vs 25%
6. 资产质量：货币资金/应收/存货/商誉/无形 占总资产比
7. 成长一致性：营收/归母净利/经营现金流 同比是否同向
8. 趋势：近 8 期关键科目 + CAGR
9. 评分卡：8 项加权 0-100 + 评级

## 财务红旗规则库（10 条）
存贷双高 · 利息收入与货币资金背离 · 应收增速远超营收 · 存货增速远超成本 · 应交税费与利润总额不匹配 · 商誉+无形占净资产偏高 · 少数股东损益与权益错配 · 经营现金流连续偏弱 · 非经常性损益占比高 · 投资活动大额净流出

## 增强风控（forensic_plus.py，本作品新增）
审计意见/内控意见、附注关键项抽取、跨期口径一致性与重述嫌疑、行业口径基准、真实盈余管理(REM)/分类转移 → 详见 [10_增强风控与造假验证.md](10_增强风控与造假验证.md)。

## 法证评分（forensics.py）
Beneish M-Score / Piotroski F-Score / Altman Z-Score / 应计质量。

## 验证要求
规则要能「命中」也要能「沉默」——用干净的高质量公司确认为 0 命中；且**必须配对照组与误报率**，否则命中率没有含金量（见 08/G、08/I）。
