# 效力验证与盲测（本作品的评估体系）

> 本文件是 08_回测结果/ 的阅读说明书。核心立场：**证明有效，而不是堆功能**；拿不出显著证据的地方如实标注。

## 一、为什么单独做评估体系
一个财报分析智能体「功能多」不等于「有效」。我们把它拆成三类可检验的命题，各自配对照与统计量：
1. **预测量效**：财报标签/风险分 → 后续「坏结果」的概率（用前向收益与负收益概率做代理）
2. **横截面选股**：多报告期 × 随机抽样 → 平均超额 / 胜率 / IC / 五档单调性
3. **造假与风险识别**：已知造假/违规公司的召回 + **对照组的误报率**

## 三、方法学铁律（血泪）
1. **留一/交叉验证必须每折重拟合**，否则「CV」恒等于样本内（曾实测 30 组配置 cv 与样本内一字不差）。
2. **报有效折数**：留出的有效折数取决于每期可用样本；样本不足时「100% 胜率」只有 3 折，必须写明。
3. **未达显著要写**：如 t=1.63(n=3)、n=11，都如实标注。
4. **造假/风险类指标必须配对照组**：只看正样本命中率会严重高估（实测「异常≥3」在对照组误报 92–94%）。
5. **先扩数据再谈策略**：小样本的最优权重大概率是过拟合。
6. **消融与基准**：去某模块看变化（证明不是堆料）、vs 规模/单因子/随机（证明不是 beta）。

## 四、主要结论（诚实）
- **因子策略未通过大样本样本外检验**（+3.54% → -2.37%）；唯一正向为规模（已知 beta）。
- **风险引擎是预筛选**：最佳 AUC 0.747、召回@前5% 27.3%、精确率仅 0.7–1.1%。
- **两轮集成优化没有提升**（0.738/0.745 < 0.747），已如实记录。
