# 周期股量价拆分与压力测试（cyclical.py）

## 定位
周期股/重资产股财报分析最核心、也最易「只能定性不能定量」的硬功夫，集中到一个模块。

## 四大能力
1. **量价拆分**：净利增速拆成「营收增速(量×价) + 毛利率提升/费用/汇兑/套保/一次性(残差)」；给出 `price_yoy`（商品价同比）即进一步拆价 vs 量。
2. **情景压力测试**：商品价 −10%/−20%/−30% → 净利影响，用经营杠杆模型（净利变动≈价格变动×商品占比×100/归母净利率）。
3. **科目穿透**：商誉占归母权益 + 减值风险 + 采矿权/探矿权需附注穿透的触发条件（可回收金额<账面价值）。
4. **异常三级定性**：危险/需核实/可解释 逐项标注 + 去重；勾稽类 fail 归入可解释（四舍五入/汇兑/少数股东）。

## 行业识别
CYCLICAL_KW（行业词）+ NAME_KW（公司名词）双路；行业从东财 F10（EM2016）取，取不到用公司名兜底。

## 端点
`GET /api/cyclical/{code}?price_yoy=&commodity_share=`

## Agent 时序纪律
提示词铁律：周期股/重资产股下结论前必须 analyze + deep_analysis 同轮交叉核对，浅深不一致以 deep_analysis 为准；禁止先浅后深、说一半改一半。

## 诚实边界
价/量拆分需外部商品价格；矿权逐项明细需财报附注；情景压力测试是经营杠杆近似，商品占比为可调参数。
