# 数据字典（字段与数据流）

## 仓库表（warehouse.sqlite3）
| 表 | 主键 | 说明 |
|---|---|---|
| stocks | code | 股票基础信息 |
| statements | code,period,kind | 三表原始条目（JSON）|
| indicators | code,period | 指标（JSON）|
| kline | code,date | 前复权日线 |
| market_snap | snap_date,code | 全市场快照（np_yoy/rev_yoy/roe/gm/np/rev/tag/board）|
| events | code,event_date | 事件流 |
| research | code | 云端批量分析结果（risk_level/verdict/track/关键指标/异常）|

## 关键字段
- np_yoy / rev_yoy：净利润 / 营收 同比增长（%）
- roe：净资产收益率（%）；gm：毛利率（%）
- tag：异动标签（亏损 / 暴雷 / 爆发），以 | 连接
- board：板块（沪主板 / 深主板 / 创业板 / 科创板 / 北交所）
- risk_score / risk_level：综合风险分（0-100）/ 等级（高/中/低）
- verdict：结论（关注 / 谨慎 / 规避）

## 数据流
akshare/东财/腾讯 → datasource/realtime → SQLite 仓库 → 加工层 → 结论层 → API → SPA / Agent / QQ
