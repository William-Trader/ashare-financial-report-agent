# 功能总览（financial-report-claw，14 工具 / 95 API / 57 模块）

## 分层
1. 数据层：akshare(东财) 三表 + 腾讯行情/K线 + 东财 datacenter 事件 → 本地 SQLite 仓库
2. 加工层：规范化 → 指标 → 勾稽 → 异常 → 深析/法证/现金流桥/增强风控
3. 结论层：扫描编排 → 报告 → 建议(关注/谨慎/规避) → 证据链 → 结论校准
4. 交互层：单文件 SPA + 自持 Agent（14 工具）+ QQ 机器人
