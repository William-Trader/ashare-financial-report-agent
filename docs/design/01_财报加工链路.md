# 财报加工链路

## 1. 取数（datasource.py）
- 东财三表：stock_balance_sheet_by_report_em / profit_sheet / cash_flow_sheet
- 统一重试退避 + 版本化缓存（改结构换 key 前缀）

## 2. 规范化（normalize.py）
- EM 三表是“年初至今累计”：单季 = 本期累计 − 同年前一报告期累计；Q1 即单季
- 同比基准 = 去年同期（report_date 年份 -1），否则会把同比算成环比
- 金融股无营业总收入/成本 → 相关比率 N/A（永不填 0）

## 3. 指标（indicators.py）
- 毛利率、归母净利率、ROE、ROA、资产负债率、净现比、收现比、扣非占比
- 单季同比/环比；分母口径（平均余额 vs 期末）

## 4. 勾稽（checks.py）
- 资产=负债+权益；流动+非流动=资产；现金期初期末勾稽；归母+少数=净利润；利润总额-税=净利润；表间净利润一致

## 5. 异常（anomaly.py）
- 非经常性损益占比、会计口径/结构突变（毛利率同比大步长）、利润与现金流背离（净现比、应收/营收错配）、商誉占比

## 设计要点
- 能自算就自算：以上比例全部从三表计算，外部只取原始数据
- 数据不显旧：报告期自动探测；行情带来源与时间戳
