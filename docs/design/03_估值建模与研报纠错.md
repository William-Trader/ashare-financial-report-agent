# 估值建模与研报纠错

## 估值建模（valuation_model.py）
- DCF(FCFF)：预测期 5 年 + 永续增长；WACC、g1、g_term、growth_fade 可配
- 相对估值：PE/PB 分位对比
- 5×5 敏感性矩阵：增速 × WACC
- 输出：基准每股价值 + 区间 + 市价对比
- 关键坑：CAPEX 代理必须用“Δ固定资产 + 折旧摊销”；用“投资活动现金流净额”会严重失真（曾把某白酒股算出每股 472 而市价 1258，偏离 +166%）。偏离市价 >60% 时主动提示复核。

## 研报纠错（report_check.py）
- 规则层：草稿数字 vs 系统事实池逐项比对；检查免责声明是否缺失
- LLM 层：逐条核验数值/口径/期间/来源/逻辑
- 输出：issues[{级别,类型,草稿原文,系统事实,建议,依据}] + 总结 + 评分
