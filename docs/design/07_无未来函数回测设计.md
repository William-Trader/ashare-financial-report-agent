# 无未来函数回测设计

## 铁律
1. 信号（选股）只用「决策日 T0 及之前已可得」的信息：报告期快照，法定披露截止后 T0
2. 收益只用「T0 之后」的前复权 K 线
3. 二者时间严格不重叠 —— 阻断一切未来函数

## 引擎（backtest.py）
- T0 = 报告期法定披露截止后的首个交易日（如 2026-06-30 → 2026-09-01）
- 10 个策略轮次（基准/综合分/单因子/加过滤/收紧持仓/缩短持有）
- 指标：组合收益 vs 基准、超额、命中率、分位数、IC（Spearman 秩相关）
- walk-forward：多个入场日（均在披露后）检验稳健性

## 实测结果（诚实披露，随样本扩充而更新）
- **小样本阶段**（K 线约 1 年、每期约 300 只）：留一超额 +3.54%(3 折)，但 7 期中仅 3 期样本充足，t=1.63 未达显著。
- **扩样后**（K 线约 3 年、每期约 2,580 只）：同一策略样本外超额变为 **-2.37%** → 原正超额是小样本假象。
- 基准对比：单因子最好为营收 +0.56%；唯一正向是规模（小市值 +1.38%，属已知 beta）；随机权重均值 -1.17%。
- 消融：去掉毛利率反而 +1.36%（扩样后毛利率为负贡献）。
- **结论：因子策略未通过大样本样本外检验。** 详见 08/H 与评估报告第十二章。

## 方法论要点
- 「留一/交叉验证」必须**每折重拟合**才算样本外；固定权重平均各期的「CV」恒等于样本内（曾实测 30 组配置 cv 与样本内一字不差）。
- 报告必须给：**有效折数 + 留出超额 + 折胜率 + t 统计量**，并注明样本内会高估。
- **先扩数据、再谈策略**：样本不足时任何「最优权重」都可能是过拟合。
