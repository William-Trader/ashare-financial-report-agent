# 财报赛道 / 财报对比 / 赛道对标

## 财报赛道分类（tracks.run）
按财报画像把全市场分层（规则确定，非 LLM）：
| 赛道 | 规则 |
|---|---|
| 爆发增长 | 净利同比≥50 且 营收同比≥30 |
| 稳健成长 | 净利同比≥20 且 营收同比≥15 |
| 质量白马 | ROE≥20 且 净利>0 且 营收同比<20 |
| 现金奶牛 | 毛利率≥40 且 0<ROE<20 |
| 困境反转 | 净利同比≥100 且 净利>0，或标签含爆发 |
| 风险规避 | 标签含亏损/暴雷 |
| 均衡其他 | 以上皆不满足 |

## 财报对比（tracks.compare）
2-6 只并排：单季营收/归母净利/同比/毛利率/ROE/净现比/收现比/扣非占比 + 风险分 + PE/PB/市值 + 勾稽。

## 赛道对标（research.peer）
给定公司 → 同赛道关键指标分位（ROE/毛利率/净现比/同比）+ 同业中位 + 同赛道高风险名单。
