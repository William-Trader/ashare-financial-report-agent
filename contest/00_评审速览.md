# 评审速览（Executive Summary）

> 3 分钟抓重点：本作品最值得看的三样东西 + 两个「我们主动推翻自己」的诚实结论。

## 一句话定位
**上市公司财务报告分析**：一个独立自持、不依赖任何外部 agent 框架的 A 股财报分析智能体——把三表吃透、把口径对齐、把异常挑出来，并且**用可复现的统计检验证明它有效、也敢于公开它无效的部分**。

## 最值得看的三样（按价值排序）
1. **08_回测结果/**（九份 XLSX + 13 章评估报告）——完整效力证据链：十轮回测 / 100 轮 / 400 轮 / 留一法 / 消融与基准 / 扩样复核 / 盲测多轮。
2. **04_功能设计详解/09_效力验证与盲测.md**——方法学（6 条铁律）。
3. **在线演示**：站点「作品演示」页（真实案例 + 诚实结论 + 技术规模）。

## 技术规模
- **14 个 Agent 工具 / 95 个 API / 57 个后端模块**
- 财报全链：三表 → 指标 → 勾稽 → 异常 → 口径守卫 → 深析（杜邦/周转/现金流形态/评分卡）→ 红旗 → 法证 → 估值（金融股自动相对估值）
- 增强风控：审计意见/内控、附注关键项、跨期口径一致性、行业基准、真实盈余管理(REM)
- 自持 Agent：LLM + 工具调用循环、双档路由、多轮记忆，**不依赖 OpenClaw**

## 两个诚实结论（本作品的底气）
1. **因子选股策略未通过大样本检验**：小样本留一超额 +3.54% → 扩样后 **-2.37%**；唯一正向是规模（已知 beta）。站点如实标注「未通过验证」。
2. **风险引擎是「预筛选」而非「造假识别器」**：盲测 7 轮，AUC 0.747、召回@前5% 27.3%、但精确率仅 0.7–1.1%；原始「异常≥3」判据在对照组误报 92–94%。

## 工程化
- 外部抓取强制超时 + 本地兜底 + 留痕；缓存容量受限；单接口被限流不拖死整站
- 性能：SQLite 全市场写入 132s→<1s、选股 25s→0.02s
- Docker 一键部署 + systemd + 双语 README

## 技术栈
FastAPI · 单文件 SPA · SQLite(WAL) · akshare/东财/腾讯 · DeepSeek 双档 · Docker
