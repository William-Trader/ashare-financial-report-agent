## 二、它是什么

把 A 股财报**从原始三表加工成可执行投研结论**的完整流水线，核心立场：

- **先给数字，再给判断**：每个结论带【依据：字段@期间】，可回源、可审计。
- **怀疑精神**：利润涨而现金流不涨、口径悄悄变、非经常性撑起盈利——这些是它盯的重点。
- **口径优先**：会计口径变化与利润-现金流背离权重最高；金融股不硬算 DCF。
- **工程化诚实**：不做「看起来漂亮」的功能堆砌，而是**能被复现、能被否证**的评估框架。

## 三、核心能力（14 个 Agent 工具 / 95 个 API / 57 个后端模块）

- **自持 Agent**：自建 LLM+工具调用循环（14 个财报工具）、双档路由（快问/深析）、多轮记忆，**不依赖 OpenClaw**。
- **财报特化全链**：三表 → 指标（单季/同比/环比）→ 勾稽 → 异常 → 口径守卫 → 深析（杜邦/周转/现金流形态/盈利质量/税负/资产质量/成长一致性/评分卡）→ 红旗库 → 法证（Beneish/Piotroski/Altman/应计）→ 估值（金融股自动相对估值）。
- **增强风控（本作品新增）**：审计意见与内控意见、附注关键项抽取、跨期口径一致性与重述嫌疑、行业口径基准、真实盈余管理(REM)/分类转移。
- **周期股专项（本轮新增）**：量价拆分（价/量/其他驱动）、情景压力测试（商品价冲击→净利影响）、科目穿透（商誉/矿权+减值）、异常逐项三级定性；周期股强制 analyze+deep_analysis 同轮交叉。
- **造假案例验证**：用红旗+异常+风险分评估已知造假/暴雷公司（带对照与误报率，见 08/G、08/I）。
- **全市场视图**：异动监测与分级、财报赛道（7 类）、全市场选股与因子分层、云端批量分析库、赛道对标。
- **决策闭环**：我的持仓（实时盈亏+仓位建议）、自选与预警、一键投研简报、五角色圆桌、结论校准（命中率/Brier）、审计日志。
- **效力验证设施**：无未来函数回测、回测实验室（100 轮）、效力验证（400 轮）、消融与基准对比、盲测多轮优化（见 08）。
- **工程化护栏**：外部抓取强制超时 + 本地兜底 + 留痕；缓存容量受限；单接口被限流不拖死整站（见 07）。
- **渠道与设施**：QQ 机器人（WebSocket 长连接）· Docker 一键部署 · systemd 服务与定时扫描 · 双语 README。

## 四、诚实结论（本作品最重要的一部分）

我们把「看起来最好的结果」逐条拿去检验，结论如下——**其中两条被我们自己推翻**：

1. **因子选股策略未通过大样本样本外检验。** 小样本（每期约 300 只）下留一超额 +3.54%(3 折)，把 K 线历史扩到约 3 年、每期约 2,580 只后变为 **-2.37%(4 期)**（见 08/H）。唯一稳健的正向信号是**规模（小市值 +1.38%）**，属已知风格 beta 而非 alpha。
2. **财务风险引擎是「预筛选」而非「造假识别器」。** 盲测 7 轮（11 家已知造假/违规 vs 全市场对照）后，最佳配置 AUC **0.747**、召回@前5% 由 18.2% 升到 27.3%，但**精确率仅 0.7–1.1%**；原始「异常≥3」判据在对照组误报率高达 92–94%（见 08/G、08/I）。
3. **优化轮次中有两轮没有提升**（集成调权 AUC 0.738/0.745 < 最佳 0.747）——我们把它也写进文档，而不是只报成功。
4. **未达统计显著的地方都标注了**（如 t=1.63、n=11），并注明样本量限制。

> 因此本作品的定位是：**一套严谨、可复现的财报分析与效力评估框架**，而非「宣称有 alpha 的策略」。
